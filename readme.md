## 🌼本地运行

### 第一步：
```bash
git clone https://github.com/matsuzaka-yuki/mizuki.git
cd mizuki
```
下载到本地，并进入目录
### 第二步
```bash
npm install -g pnpm
pnpm install
```
安装所需要的环境
### 第三步
根据需求修改相关文档

功能模块位于
`src/config.ts`进行修改
### 第四步
在mizuki路径下运行：
```bash
pnpm dev
```
点击http://localhost:4321进入网站
